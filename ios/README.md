# iOS workspace status

This repository's product target is now **Android-only**. No iOS app, Xcode project, TrollStore payload, exploit, or iPhone installer is built from this directory.

The Android APK can re-sign existing IPA files using the upstream zsign engine and valid user-supplied signing credentials. It cannot compile a native iOS project with Apple's SDK, and direct installation to iPhone from Android is not implemented.

This directory is retained only as a scope note to avoid implying that an iOS companion app already exists.
